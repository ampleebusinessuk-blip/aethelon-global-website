Erklärung zur Barrierefreiheit

Unser Engagement

Aethelon Global möchte, dass jeder diese Website nutzen kann. Wir streben die Einhaltung der Web Content Accessibility Guidelines (WCAG) 2.2 auf Stufe AA an.

Was wir erreicht haben

Unsere Seiten verwenden semantische Überschriften und Orientierungspunkte, tastaturbedienbare Menüs, sichtbare Fokusindikatoren, Textalternativen, ausreichende Farbkontraste, untertitelungsfähige Videoplayer und berücksichtigen Einstellungen zur Bewegungsreduzierung.

Bekannte Einschränkungen

Einige Hintergrundvideos dienen dekorativen Zwecken und verfügen über keine Audiodeskription. Sollten Inhalte schwer zugänglich sein, lassen Sie es uns bitte wissen.

Feedback

Sollten Sie auf ein Hindernis stoßen oder Informationen in einem anderen Format benötigen, senden Sie eine E-Mail an hello@aethelonglobal.com. Wir bemühen uns, innerhalb von fünf Werktagen zu antworten.

Zuletzt aktualisiert am 17. November 2026. Dies ist eine Vorlage für den Start – lassen Sie sie vor der Veröffentlichung von einem Rechtsexperten prüfen.

Lassen Sie uns gemeinsam aufbauen.
